Hallo Angelika,

wir bauen gerade das Bewerbungsformular für die neue PÜSPÖK-Website. Damit Bewerbungen direkt in Personio ankommen, brauchen wir zwei Angaben aus eurem Personio-Account:

1. **Recruiting API Schlüssel**
2. **Unternehmens-ID (Company ID)**

### So findest du die Daten:

1. In **Personio einloggen**
2. Links unten auf das **Zahnrad** (Einstellungen) klicken
3. Unter **Integrationen → API-Zugriffsdaten** findest du beides
4. Beim Recruiting API Schlüssel auf **"Kopieren"** klicken

Falls du die Seite nicht siehst, brauchst du Admin-Rechte bzw. Bearbeitungsrechte für "Marketplace & Integrationen".

### Sicherheit

- Der Schlüssel wird **nur serverseitig** gespeichert (nicht im Website-Code sichtbar)
- Er läuft **nicht ab**, kann aber jederzeit in Personio zurückgesetzt werden
- Bitte den Schlüssel **nicht per E-Mail**, sondern z.B. über einen sicheren Kanal (Signal, 1Password-Link o.ä.) schicken
